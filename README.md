# Joy Of Painting (Extended Canvases)

I am not the original creator of this mod. (https://modrinth.com/user/xerca)

I have specifically extended the 1.21.1 version of Joy of Painting for larger canvases, to be compatible with the current version of Cobblemon. I have no intention of maintaing this off-shoot beyond my own personal devices, or compete with the original mod. I offer it here for others playing cobblemon that would like larger canvases.

![poliwag_start_painting](https://misnina.neocities.org/poly_start_small.gif)

Adds:
- Extra Large, Extra Tall, Extra Long Canvases (48 pixel based, 3 blocks)
- Super Large, Super Tall, Super Long Canvases (64 pixel based, 4 blocks)

Issues:
- I'm terrible at alignment, the GUI of the paintings are off centered. It drives me insane pushing numbers back and forth and relaunching, so you get to live with it! :D
- I don't know how to properly fork if there was a better way than just starting a new repository.
